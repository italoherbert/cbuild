Notas da versão 1.7

Atualizado o xutest para versão 1.2, onde foi consertado problema com o caminho relativo de arquivo de programa principal que fazia referência a arquivos cabeçalhos com testcases implementados neles. Não era um erro crítico, dado que o foxmake só utiliza caminhos absolutos para compilar e linkar. Logo, o erro só aparecia quanto o xutest era utilizado sem o foxmake!

Foi consertado problema com a possibilidade de o usuário informar um diretório inexistente ou um arquivo no --working-dir

Foi consertado problema com a possibilidade do usuário informar um diretório no --script

Como instalar?

Instalando no windows

Para instalar no windows, você pode extrair a versão zipada: foxmake-x.x-windows-x64.zip (onde x.x é a versão) e fazer a variável de ambiente PATH apontar, também, para o diretório extraído (ou onde o arquivo executável "foxmake.exe" estiver.)

Caso queira utilizar a biblioteca xutest, basta copiar as pastas "lib" e "include" para raiz de onde estiver instalado o mingw ou semelhante. Se estiver utilizando o mingw64, copie as pastas "lib" e "include" para pasta "x86_64-w64-mingw32" do mingw64.

Atenção:
Caso o windows bloqueie o foxmake

Se o windows bloquear o foxmake, pode ser devido a alguma Política de Restrição de Software ou Controle de Aplicativo do Windows Defender. Isso significa que, provavelmente por o foxmake ser pouco utilizado ou não ter assinatura digital, o windows entenda que ele pode não ser confiável. Mas é! Para desbloquear o foxmake, neste caso, você pode fazer o seguinte:

  • Clique no foxmake com o botão direito do mouse
  • Vá em propriedades
  • Na aba Geral, marque a opção Desbloquear
  • Se isso não resolver, o "Controle Inteligente de Aplicativos" do Windows pode estar bloqueando o foxmake e pode ser necessário desativá-lo.

Instalando no linux

Se estiver no Ubuntu, ou outra distro derivada do Debian, pode fazer o download do pacote .deb: foxmake-x.x-linux-x64.deb (Onde x.x é a versão) e executar o seguinte comando:

sudo dpkg -i foxmake-x.x-linux-x64.deb
Atenção:

Se já tiver instalado o xutest ".deb", deve desinstalá-lo antes de instalar o foxmake versão ".deb". Pode utilizar o seguinte comando: 

sudo dpkg -r xutest

Se preferir a versão .tar.gz, basta baixar o arquivo: foxmake-x.x-linux-x64.tar.gz, descompactar, e copiar o executável "foxmake" para pasta /usr/bin ou criar um link simbólico nessa pasta para o executável "foxmake".

Caso queira utilizar a biblioteca xutest, você pode copiar o arquivo "libxutest.a" para pasta /usr/lib/x86_64-linux-gnu (isso caso esteja num derivado do debian), e copiar o conteúdo da pasta "include" para pasta /usr/include.

Você pode optar por não instalar o xutest e incluí-lo diretamente no seu projeto. Veja como fazer essa configuração em: testes com xutest.
